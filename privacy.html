Privacy Policy

Last updated: October 18, 2026

AGREL Backup is a personal-use, self-hosted backup system operated by its owner.

Google Drive Access

The application uses Google OAuth and rclone to access files created or used by the application in the owner's Google Drive.

Data Usage and Storage

Google Drive access is used only to upload, retrieve, verify, and manage backups. Backup file contents and names are encrypted using rclone crypt before upload.

OAuth credentials are stored locally on the owner's server. Encrypted backup data is stored in the owner's Google Drive account.

Data Sharing

The application does not sell user data or use Google user data for advertising. Data is transferred to Google Drive as the selected storage provider and is not intentionally shared with other users.

Access and Revocation

The owner can revoke the application's Google account access through Google Account settings.
